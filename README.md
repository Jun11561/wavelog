# wavelog

전시장에서 NFC 태그에 휴대폰을 대면 열리는 **음악 취향 체험용 모바일 웹앱**입니다.
아티스트 카드를 넘기며 대표곡을 들어 보고 한 팀을 고르면, 그 아티스트와 비슷한 곡 리스트를 보여 주고
결과를 **이미지로 저장**하거나 현장 포토프린터로 **영수증처럼 출력**할 수 있습니다.

## 체험 흐름

```
NFC 태깅 → 시작 안내(터치) → 아티스트 캐러셀(대표곡 자동 재생) → 결과(유사곡 4곡) → 이미지 저장 / 영수증 출력 → 완료
```

| 화면 | 경로 | 내용 |
|---|---|---|
| 시작 안내 | `/` | 첫 터치로 모바일 오디오 자동재생 잠금 해제 |
| 아티스트 선택 | `/select` | 9팀 무한 루프 캐러셀, 가운데 카드의 대표곡 재생 |
| 결과 | `/result/:artistId` | 선택한 아티스트·대표곡 + 유사곡 리스트, 사진 저장·영수증 모달 |
| 출력중 / 완료 | `/printing`, `/done` | 포토프린터 출력 요청과 상태 표시 |

## 기술 스택

React 18 · TypeScript · Vite · React Router  
외부 UI 라이브러리 없이 캐러셀·모달·결과 이미지 렌더링을 직접 구현했습니다.

## 구현 포인트

**모바일 오디오 자동재생 잠금 해제** — `hooks/useAudioPlayer.tsx`  
모바일 브라우저는 사용자 제스처 없이 소리를 재생하지 않고, iOS는 소스 없는 `play()`로는 권한을 주지 않습니다.
첫 터치 이벤트 안에서 짧은 무음 WAV를 한 번 재생해 잠금을 풀고, 앱 전체가 `<audio>` 하나를 공유하도록 Context로 묶어
카드가 바뀔 때마다 이전 곡을 끊고 새 곡을 재생합니다.

**무한 루프 캐러셀** — `components/Carousel.tsx`  
실제 인덱스 대신 가상 위치를 기준으로 가운데 주변 카드 5장만 렌더링해 끝없이 넘길 수 있게 했습니다.
카드 폭은 `ResizeObserver`로 실측해 Figma 기준 간격·화살표 위치를 비례 계산하고,
포인터 이벤트로 스와이프를 처리하되 일정 거리 이상 움직였을 때만 드래그로 전환해 옆 카드 탭과 충돌하지 않게 했습니다.

**결과 이미지를 캔버스로 직접 그리기** — `components/resultImage.ts`  
처음엔 DOM 캡처(html-to-image)를 썼지만 iOS Safari에서 큰 이미지가 빠진 채 캡처되는 문제가 있었습니다.
그래서 미리보기와 같은 레이아웃을 Canvas 2D 좌표로 다시 그리도록 바꾸고(3배 해상도, 폰트 로드 대기, `object-fit: cover` 재현, 말줄임 처리),
이미지 하나를 못 불러와도 저장은 되도록 실패한 칸만 회색으로 채웁니다.

**기기 대응** — 아이폰 표시 문제, 구형 기기·짧은 화면 레이아웃, iOS 글자 자동 확대 방지를 실기기 기준으로 맞췄습니다.

**목업 ↔ 백엔드 전환** — `config/appConfig.ts`, `api/client.ts`  
기획·디자인 변경에 대응하도록 동작 옵션(터치 시작 여부, 안내 시간, 스와이프, 목업 사용)을 한 파일에 모았고,
백엔드가 준비되기 전에는 목업 데이터와 가짜 출력 지연으로 전체 흐름을 시연할 수 있습니다.

## 실행

```bash
cd frontend
npm install
npm run dev     # 같은 Wi-Fi의 휴대폰에서도 접속 가능 (--host)
```

폴더 구조와 백엔드 연동 방법은 [frontend/README.md](frontend/README.md)에 있습니다.
